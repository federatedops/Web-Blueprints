This is the first post on the Web Blueprints demo site. Like every page here,
it's a Markdown file in the repository: `src/content/news/2026-11-17-hello-world.md`.

## What's in the blueprint

- **Production deploys**: every push to `main` rebuilds the live site.
- **Pull-request previews**: every pull request gets its own copy of the
  site, rebuilt on each push and deleted when it closes.
- **Markdown content** with typed frontmatter, so mistakes fail the build
  instead of reaching the live site.
- **Images sized for you**, including 1200×630 share cards.
- **News** with categories, pagination and full-archive search, all static.
