Static sites with built-in previews

Ship a company website the way you ship code.

Content in Markdown, pages built by Astro, hosting on GitHub Pages, and a live preview of every pull request before it merges.

How it worksView on GitHub

Every pull request gets its own site

Open a pull request and a full copy of the site is built and published at its own address, linked from a comment on the PR. Reviewers click through real pages instead of reading diffs.

Push again and the preview updates. Merge or close the PR and the preview is deleted.

See the CI/CD setup

Editors write Markdown

Pages and news posts are plain Markdown files with a few typed fields at the top. A missing or misspelled field fails the build with the file name, so mistakes surface in the pull request, not on the live site.

Images sized for you

Drop in one large photo. The build makes every size the site needs, in WebP, plus a 1200×630 crop for Facebook, LinkedIn and X share cards.
